# 🤖 AI PDF Assistant (Gemini-Powered)

Այս նախագիծը ստեղծվել է որպես *AI Engineering Apprenticeship*-ի ընդունելության առաջադրանք: Հավելվածը թույլ է տալիս օգտատիրոջը բեռնել PDF ֆայլեր և ստանալ պատասխաններ դրանց բովանդակության վերաբերյալ՝ օգտագործելով Google Gemini AI-ն:

## ✨ Հիմնական Հնարավորություններ
* *PDF Մշակում.* Ծրագիրը հաջողությամբ կարդում և մշակում է PDF ֆայլերը՝ տեքստի արտահանման միջոցով:
* *AI Հարց ու Պատասխան.* Ինտեգրված է Google Gemini API-ի հետ՝ բեռնված փաստաթղթի հիման վրա հարցերին պատասխանելու համար:
* *Streamlit UI.* Պարզ և ինտուիտիվ ինտերֆեյս՝ օգտատիրոջ հարմարավետության համար:

## 🛠 Տեխնոլոգիաներ
* *Լեզու:* Python
* *Framework:* Streamlit
* *AI SDK:* Google Generative AI (Gemini)
* *PDF Library:* PyPDF2
